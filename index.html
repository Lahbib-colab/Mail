Connexion à vos vraies boîtes mail

Gmail et Outlook / Microsoft 365 se connectent directement depuis cette page (OAuth, aucun mot de passe saisi ici). Créez un « ID client » gratuit pour chaque service et collez-le ci-dessous. iCloud et IMAP exigent un serveur relais : impossible depuis un navigateur seul.

Comment obtenir les ID clients ?

Google : console.cloud.google.com → nouveau projet → activer « Gmail API » → écran de consentement OAuth (Externe, ajoutez votre adresse comme utilisateur test) → Identifiants → ID client OAuth → Application Web → « Origines JavaScript autorisées » : l’adresse exacte du site (ex. https://pseudo.github.io).

Microsoft : entra.microsoft.com → Inscriptions d’applications → Nouvelle (comptes de tous annuaires et comptes personnels) → URI de redirection de type « Application monopage (SPA) » = l’adresse exacte de cette page, fichier compris → Autorisations API → Microsoft Graph, déléguées : Mail.ReadWrite, Mail.Send, User.Read.
